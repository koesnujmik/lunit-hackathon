# Lunit Hackathon

Submission harness for the Lunit Hackathon HealthBench track.

## Submission Branch

```text
lunit/hackathon-submission
```

## Notes

- Final answers must be generated by Lunit L2.
- Do not commit API keys, local `.env` files, or dashboard secrets.
- The evaluation environment is isolated, so runtime dependencies must be declared explicitly.
