# Lunit Hackathon

Basic submission harness for the Lunit Hackathon HealthBench track.

## Submission Branch

```text
lunit/hackathon-submission
```

## Notes

- Final answers must be generated by Lunit L2.
- Do not commit API keys, local `.env` files, or dashboard secrets.
- The evaluation environment is isolated, so runtime dependencies must be declared explicitly.

## Quick Start

Create a local environment file from the example:

```bash
cp .env.example .env
```

Then edit `.env` and set your team API key:

```bash
export LUNIT_FM_API_KEY="lunit_..."
export LUNIT_FM_API_URL="https://model.hackathon.lunit.io"
export LUNIT_FM_MODEL="Lunit/L2-preview"
```

Run a single L2 answer:

```bash
source .env
PYTHONPATH=src python -m lunit_hackathon.run_once "환자가 갑자기 흉통과 호흡곤란을 호소합니다. 어떻게 안내해야 하나요?"
```

Run a basic 3-turn Patient Simulator conversation:

```bash
source .env
PYTHONPATH=src python -m lunit_hackathon.run_simulator --turns 3
```

Simulator logs are written under `logs/` and are ignored by git.
